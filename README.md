# 💫 About Me:
I am a third-year Computer Science Engineering student specializing in Artificial Intelligence and Machine Learning, passionate about developing innovative, user-focused technology solutions. My flagship project, **Fitness Messer**, is an Android fitness application that combines exercise tracking, gamification, progression systems, and virtual kingdom building to encourage consistent physical activity. I am also developing **CodeQuest AI**, an AI-powered coding mentor featuring programming practice, debugging assistance, progressive hints, and personalized learning; **MovieMark**, a digital filmmaking collaboration platform focused on connecting creators and enabling creative opportunities; and **MythoVerse**, an interactive mythology learning platform designed to make traditional knowledge more accessible.<br><br>My technical interests include Python, Java, C, AI/ML, mobile application development, full-stack development, database integration, and AI-assisted software engineering. I work with technologies such as React Native, Expo, TypeScript, Flask, Git, and GitHub, depending on project requirements. I am interested in building intelligent applications, exploring emerging technologies, and applying software engineering and problem-solving skills to real-world challenges. Through personal projects and hackathon participation, I aim to strengthen my technical expertise and contribute to impactful, scalable digital solutions.
